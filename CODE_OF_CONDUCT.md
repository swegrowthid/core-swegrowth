# Kode Etik

Repo ini bagian dari komunitas SWE Growth, jadi aturan yang sama berlaku di issue, pull request, dan diskusi
di sini. Versi lengkapnya ada di [swegrowth.id/code-of-conduct](https://swegrowth.id/code-of-conduct)
(sumbernya `app/routes/code-of-conduct.tsx`).

Ringkasnya:

- Hormati semua orang, apa pun latar belakang, pengalaman, dan level kariernya.
- Kritik kode dan ide, bukan orangnya. Pertanyaan pemula itu wajar.
- Tidak ada pelecehan, diskriminasi, spam, atau promosi tanpa izin.
- Jangan membagikan data pribadi orang lain (termasuk data member dari portal).

Pelanggaran bisa dilaporkan secara privat ke maintainer ([@zikrulihsan](https://github.com/zikrulihsan)) atau ke
admin komunitas. Maintainer berhak menghapus komentar, menutup issue/PR, atau memblokir akun yang melanggar.

Kode etik ini terinspirasi dari [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
